This register records external images currently added during the visual-quality audit. Each lesson should also display a nearby caption and source link. Always check the original file page if you plan to reuse or adapt an image.

Visual standard: real photographs, dissection specimens, radiological images and histological micrographs should be identified as such. Original diagrams are labelled as schematics or illustrations. A drawing must never be presented as a real micrograph.

Rules for future images and Pro features

  • Record creator, source page, licence, date checked and the lesson where each image appears.
  • For any paid Pro experience, use images whose licence permits commercial use, or obtain permission from the rights holder.
  • Do not assume that an image is reusable because it appears in a search engine.
  • When an image is cropped, recoloured, labelled or otherwise adapted, check the licence requirements and mark the adaptation where required.
  • Keep educational photographs and micrographs distinct from generated artwork and schematic diagrams.
