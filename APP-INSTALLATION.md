# Install the Anatomistvitalis app

Anatomistvitalis is published as an installable Progressive Web App (PWA). It uses the website's existing content and can be added to a supported phone or computer's home screen/app launcher. It is not an Android APK or an App Store package. Installation support depends on the browser and device.

## Android (Chrome)

1. Open https://olaraphael.github.io/Anatomistvitalis_Academic_Resource_center/ in Chrome.
2. Tap **Install app** on the website if the browser offers it. Alternatively, open Chrome's three-dot menu and choose **Install app** or **Add to Home screen**.
3. Confirm the installation. The app icon should appear with your other apps.

## iPhone or iPad

1. Open the site in Safari.
2. Tap **Share**.
3. Choose **Add to Home Screen**, then confirm.

## Computer

Open the site in a supported browser such as Chrome or Edge and use the browser's install icon or menu option when available.

## If the Install button does not open a prompt

1. Confirm that you opened the live HTTPS address above, not a GitHub file preview or a downloaded HTML file.
2. Open the site in **Google Chrome on Android**, reconnect to the internet, and reload the page.
3. Open Chrome's three-dot menu. If available, choose **Install app** or **Add to Home screen**. The in-page button can only open the native prompt after Chrome has decided the site is installable; browsers do not expose that prompt in every situation.
4. If the menu item is absent, close other copies of the site, update Chrome, reopen the site, and try again later. An already-installed app may not show the install prompt again.
5. After a site update, reload the website online. If an old version remains, close the app and reopen it.

## If installation still does not appear

The website is an installable web app, not a downloadable APK. A website button cannot force a browser to install it when the browser has not offered its native install prompt. On Android, use the live HTTPS website in Chrome, refresh it online, then open Chrome's **⋮** menu and choose **Install app** or **Add to Home screen** if shown. If that option is missing, try updating Chrome and reopening the site. Some Android browsers create only a home-screen shortcut rather than a full app installation.

## Offline limitations

The app caches the main learning page and original diagrams after the first successful online visit. The lesson library, quiz and locally saved progress may work offline once cached, but an initial connection is needed, and not every browser/device handles offline storage identically. Progress is stored in that device's browser and does not sync to other devices.

## App updates

When the site is updated, reconnect to the internet and reopen the app so the browser can fetch the latest version. If an older version remains visible, close and reopen the app or reload it after reconnecting.

## Privacy

This version does not create student accounts or sync data to a server. Quiz interactions run in the browser, and lesson-completion data is stored locally on the user's device.
